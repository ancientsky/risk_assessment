# 方法說明：疫情新聞查證與我國快速風險評估

本文件說明本工具採用之各項架構、各架構如何對應到 `assessment.json` 欄位與確定性計算，
以及**每份參考文件在開發時是否實際取得原文**。評估者操作指引（給模型與分析員閱讀）另見
`src/epi_risk_agent/prompts/methodology.md`；本文件為設計依據與引用。

> 誠實聲明：開發環境之網路僅允許直接連線 `who.int` 與 `cdc.gov.tw`。下表「取得情形」欄如實記錄；
> 標示「未取得原文」者，其內容僅依網路搜尋結果摘要確認架構與要點，**本工具並未逐字重現其表格或定義**，
> 相關量表、矩陣與問題皆為本工具自訂並明示於下。正式採用前，建議取得原文核對。

## 2. 流程

```
新聞輸入（txt/md/html/pdf/網址/圖片）
  → [J] 分流與陳述擷取 → 多來源查證（判定＋來源分級）→ 新聞可信度
  → [A–C] 證據蒐集：病原/傳播特性 → 國際疫情 → 我國現況
  → [A–G] 逐項評估：機率 1–5、衝擊 1–5、等級定義、分層、信心程度（LLM／分析員判斷，附引用）
  → 確定性計算：矩陣 → 三級 → 綜合研判；信心上限；一致性與引用檢核（scoring.py）
  → [I][H] 升級篩檢；情境、觸發指標、決策選項、建議事項
  → 單一自足 HTML 報告
```

核心原則：**判斷由人或模型做並附引用；合成由程式做**。程式從不覆寫判斷者的建議等級，而是把「建議」與「計算」並列，差異列為警告交由審閱者裁定。

## 4. 機率、衝擊與矩陣（本工具自訂，`scoring.py`）

### 4.1 量表
機率（評估期間內發生之可能性，預設未來 3 個月）：1 極低（約 <1%）、2 低（1–10%）、3 中（10–50%）、4 高（50–90%）、5 極高（>90%）。
量化錨點參考 G 主張「以數值區間界定機率」之精神，**區間數值為本工具自訂**。

衝擊（假設該情形發生時對我國之後果）：1 極低 … 5 極高，描述涵蓋 A–C 衝擊列之要素（嚴重度、易感族群、疫苗與治療、防治可行性、醫療量能、社會衝擊）。完整定義見 `prompts/methodology.md` §3.3。

### 4.2 風險矩陣（版本 `epi-risk-5x5-v1`）

| 機率＼衝擊 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| **5** | 中 | 高 | 高 | 極高 | 極高 |
| **4** | 低 | 中 | 高 | 極高 | 極高 |
| **3** | 低 | 中 | 中 | 高 | 高 |
| **2** | 低 | 低 | 中 | 中 | 高 |
| **1** | 低 | 低 | 低 | 低 | 中 |

等同於以乘積 P×I 分段：≤4 低、5–9 中、10–15 高、≥16 極高（測試 `test_matrix_table_matches_documented_banding` 檢查兩者一致、對稱且單調）。
四級命名比照 ECDC 式「低／中／高／極高」，**此表非 F 原表之重現**（原文未能取得）。

### 4.3 對應至三級（保留兩者）
- 矩陣四級 → 三級：低→低、中→中、高→高、極高→高（報告同時顯示矩陣等級與三級）。
- 衝擊項目只有衝擊分數：1–2 低、3 中、4–5 高。
- 機率類項目未填 `impact` 時，沿用衝擊項目之分數（多個衝擊項目取最大）。
- **綜合研判** = 各機率類項目矩陣等級之最大者（並記錄由哪一項決定）。

校驗：以三篇文章之結論回推——COVID-19（境外移入高 × 衝擊高）→ 4×4＝極高 → 高 ✔；SFTS（中 × 中）→ 3×3＝中 ✔。茲卡文章未給單一綜合等級，其分層結果以 `strata` 表達。

### 4.4 信心程度與上限（D、E、F 均要求附信心／不確定性）
判斷者先給「高／中／低」與理由，程式再依來源情形設上限：
- 評估內容全未引證 → 低；
- 引用來源僅單一發布者（不含新聞本身）→ 中；
- 無第 1、2 級來源（僅媒體或未知）→ 低；
- 全部來源僅取得搜尋摘要或未取得全文 → 中；
- 超過 30% 評估內容未引證 → 中。
整體信心 = 各項目有效信心之最小值；若有關鍵陳述未通過查證規則，再設上限「中」。

## 5. 新聞查證（J）

- 判定：已證實／部分證實／無法證實／與官方資訊不符／過時。
- 來源分級：1 官方衛生機關／國際組織 ＞ 2 同儕審查文獻 ＞ 3 主流媒體（ProMED 歸此級）＞ 4 社群／未知。
- 取得方式：全文／搜尋摘要／未取得（每個來源必填，反映**本次**實際取得情形）。
- 確定性規則（`scoring.audit_claim`）：
  - 「已證實」「部分證實」需 ≥1 個「支持」來源：具網址、非新聞本身、發布者與新聞不同、且非「未取得」。否則列為**錯誤**並建議改為「無法證實」。
  - 「已證實」僅由第 3、4 級來源支持 → 警告。
  - 「與官方資訊不符」需 ≥1 個第 1 級「反駁」來源。
  - 「過時」需 ≥1 個具網址之來源。
- 新聞可信度（程式計算）：關鍵陳述之有效判定（未通過規則者以建議判定計）取平均分數（已證實 1、部分證實 0.6、過時 0.4、無法證實 0.25、不符 0）；≥0.8 高、≥0.5 中、其餘低；任一關鍵陳述與官方不符 → 低；新聞來源屬第 4 級者上限為中。

## 6. 升級篩檢

- **IHR 附件二（I）**：四問題（嚴重影響、不尋常或非預期、國際傳播顯著風險、旅行或貿易限制顯著風險）。程式計算「是」之數目，≥2 即達門檻；天花、野生型小兒麻痺、新亞型人類流感、SARS 一律通報。我國非 WHO 會員，本工具以「事件發生國之角度」套用，作為我國研判升級之參考，並於報告中說明角度。
- **人畜共通／新興病原（H）**：六題改編問題（是否已知人畜共通病原、本事件人類感染證據、持續人傳人證據、宿主／病媒是否存在於我國、我國暴露途徑、有無疫苗或特效治療）。事件類型為「人畜共通」或「新興或不明病原」而未填答時，檢核提示。

## 7. 決策支援

- **情境**：最佳／最可能／最壞，各有假設、隱含等級與意涵。
- **觸發指標**：可觀察、具門檻、指明監測來源與目前狀態；至少一項升級、一項降級（缺少時警告）。
- **長官決策建議**：決策問題、2–4 個選項（優點、缺點、主責單位、時程 24 小時／1 週／1 個月、所需資源）、恰一項建議方案（無建議方案為錯誤）。
- **再評估日期**：須晚於產出日。

## 8. 報告呈現原則

- 單一 HTML 檔，CSS／JS／圖示全部內嵌，無任何外部請求（測試 `test_no_external_resources`）；可離線、可列印為 A4。
- 等級以「文字＋圖形符號（●▲◆■）＋顏色」三重編碼，矩陣高／極高格另加 45°／135° 斜線；不單靠顏色。
- 淺色／深色主題以 CSS 變數定義，並支援使用者切換；手機寬度（390px）下表格改為卡片式，無水平捲動。
- 互動：矩陣點選顯示項目證據（可鍵盤操作）、情境試算（明確標示「試算」，不影響正式結果，且與 Python 使用同一矩陣資料）、建議事項篩選、圖表懸停提示與表格檢視。

## 9. 已知限制

- F、G、H、I、J 原文未能於開發環境取得；相關量表、矩陣、HAIRS 問題為本工具自訂或改編，需由使用單位以原文核對後決定是否調整。
- 機率與衝擊分數仍為主觀判斷；本工具使其**透明、可稽核、可重現**，但不保證判斷正確。
- 綜合研判採「最大值」規則，屬保守設計；若使用單位偏好其他合成方式（例如加權），需修改 `scoring.audit` 並更新測試。
