# 階段三：蒐集我國情境與國際評估證據

依方法第 2 節之順序，用 web_search／web_fetch 蒐集：
1. 病原／傳播特性（潛伏期、可傳染期、致死率、高風險族群、治療、疫苗）。
2. 國際疫情：事件所在國與區域近期病例、移入他國情形、WHO／ECDC 等既有風險評估與旅行／貿易建議。
3. 我國現況：法定傳染病分類與通報時限、歷年病例、檢驗量能、病媒／宿主分布、疾管署旅遊疫情建議等級（cdc.gov.tw）、感染管制或防治指引、近期新聞稿或致醫界通函。

優先 cdc.gov.tw、who.int、ecdc.europa.eu、cdc.gov、JIHS/NIID、KDCA、ProMED 與同儕審查文獻。
以條列文字輸出「證據筆記」：每條含事實、數字、日期與來源網址；註明資料缺口。
